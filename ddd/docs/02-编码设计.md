# 编码设计（Coding / 架构设计）

## 1. 分层架构（Layered Architecture）
依赖规则：**外层依赖内层，内层不依赖外层。**

```
Presentation  (main.cpp / console 演示 / tests)
      │ 调用
      ▼
Application 应用层  order_application_service(用例编排, 事务边界, 查询)
      │ 使用接口
      ▼
Domain 领域层  Order(聚合) OrderItem Entity / Money/Id/Address VO / OrderRepository(接口) / 领域服务 / 事件
      ▲ 实现(依赖倒置)
      │
Infrastructure 基础设施层 in_memory_order_repository / 事件订阅 / 持久化
```

- **Domain**：只含纯业务逻辑，**不 import** 任何 App/Infra 头文件；仓储以**抽象接口**形式存在。
- **Application**：编排用例、定义 DTO、调用仓储接口；不写业务规则。
- **Infrastructure**：实现仓储、持久化、消息基础设施。
- **Presentation**：入口与展示。

## 3. 关键技术决策

### C++ 版本与特性
- C++17：`std::variant`、`std::optional`、结构化绑定、`if constexpr`。

### 统一返回值 `Result<T,E>`（替代跨层异常）
业务错误用**值**返回 `Result<T>`（`T=ok`，`E=业务错误码/消息`），
杜绝在领域层 throw 作为流程控制；只有在编程错误（如非法转换）才允许异常。
```cpp
auto r = service.create(customer, addr);
if (!r.good()) { log(r.error()); }
```

### 领域错误 `DomainError`
带 `code` 与 `message`，枚举：`EmptyOrder / InvalidQuantity /
InvalidStatusTransition / OrderLocked / AlreadyShipped / ItemNotFound / NotFound`。

### 值对象不可变（Value Object Immutability）
`Money`、`OrderId`、`Address` 等字段私有、只读，提供工厂与组合运算符（`operator+` 等）。

### 聚合完整性（Aggregate Boundary）
`Order` 是聚合根，`OrderItem` 只能通过 `Order` 的方法创建/增删——**不允许外部持 OrderItem 引用直接改**。
不变量在每个公共方法内 `ensure(...)` 自检。

### 依赖倒置（Dependency Inversion）
`OrderRepository` 定义为**纯抽象接口**，位于 Domain 层；
`InMemoryOrderRepository` 位于 Infra 层实现。Application 只依赖接口。

### 领域事件（Domain Event）
聚合在写操作后通过 `DomainEventPublisher`（抽象）发布事件；默认同步执行。
本示例注入一个简单记录型发布器（`Infra`），便于打印交易流水。

### 查询与命令分离（CQRS 之 Query 优化）
读模型 `OrderDto` 由应用层在 Infra 上拼装，避免把查询结果塞进领域聚合。

## 4. 关键接口（示意）
```cpp
// Domain layer
class OrderRepository {
 public:
  virtual ~OrderRepository() = default;
  virtual std::optional<Order> findById(const OrderId&) const = 0;
  virtual void save(const Order&) = 0;
  virtual void remove(const OrderId&) = 0;
  virtual std::vector<Order> findPage(int offset, int limit) const = 0;
};

// Application layer
class OrderApplicationService {
 public:
  Result<OrderId> createOrder(const CustomerId&, const Address&);
  Result<void>    addItem(const OrderId&, std::string name, int qty, Money price);
  Result<void>    removeItem(const OrderId&, size_t index);
  Result<OrderDto> submit(const OrderId&);
  Result<void>     cancel(const OrderId&, std::string reason = {});
  Result<std::vector<OrderDto>> listOrders();
};
```
